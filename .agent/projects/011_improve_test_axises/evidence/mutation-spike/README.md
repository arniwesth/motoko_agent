# Evidence: the mutation spike behind ADR-003

Produced 2026-10-05 and -06 in a throwaway worktree, `/workspaces/motoko_agent-spike-mut`, branch
`spike/011-mutation-operator-feasibility`, forked from `259265b5`. AILANG v0.47.2 (`e939cba`).
That branch never merges. This folder is what survives it.

Read `../../NOTE-spike-findings-mutation-operator-feasibility.md` for the results and
`../../PLAN-spike-mutation-operator-feasibility.md` for what was predicted before each part ran.

## What is here

- `mutants.tsv` — one row per mutant and control across parts 1 to 4. Part 5's rows are in
  `results/part5-score.txt`. **Generated by
  `scripts/make_table.py` from the run output**; no cell was typed. A `site` is the line where the replaced
  text starts, which for a multi-line edit is a line or two above the changed token.
- `scripts/` — as they ran, from `tmp/spike/` in the spike worktree. They expect that layout.
  - `mutants.py`, `mutants3.py`, `mutants4.py` — the edits. Each refuses a replacement that does
    not match exactly once.
  - `predictions2.tsv`, `predictions3.tsv`, `predictions4.tsv` — written before the rows they
    predict. Part 1's predictions are the `predict`, `gate` and `signature` fields of `mutants.py`.
  - `run_set.sh`, `run_all.sh`, `sweep_one.sh`, `sweep_all.sh` — part 1.
  - `run_probe_all.sh` — part 2. `run_set3.sh`, `run_all3.sh` — part 3. `run_probe4.sh` — part 4.
  - `score*.py` and `score*_selftest.py` — each scorer and the planted cases it was run on first.
  - `spike_families_on_bank.diff` — the probe, as a diff against `scripts/dst/corpus_pr_dst.ail`.
  - `prototype.diff`, `proto_apply.py` — part 4's prototype of the rule changes. Never merged.
  - `prototype2.diff`, `proto2_apply.py`, `mutants5.py`, `predictions5.tsv`, `run_probe5.sh`,
    `score5.py` — part 5: the amended rules and the reviewers' six mutants.
  - `drive6.sh`, `compare6.py`, `control6.sh` — part 6: `make eval_matrix` without and with the
    prototype, their comparison, and the known-bad control. The generated `MATRIX.tsv` files and
    the suites' raw logs are not committed; `results/part6-*` holds the comparison, each run's
    suite exit codes and the known-bad control's lines.
  - `Makefile-private-paths.diff` — the one edit the spike worktree carried: private output paths
    for seven fixed `/tmp` names, so another session's sweep could not overwrite them.
- `results/` — each part's score table and sequence log, and the summary block of each full sweep.

## What is not here

The raw gate logs, the corpus wire captures and the full sweep logs: about 50 MB, in
`tmp/spike/out*` of the spike worktree until that worktree is removed.

## The hashes are self-attested

Each sequence log records the sha256 of its scripts and predictions when it started. `tmp/` is
ignored by git, so nothing outside the worktree timestamped them. Committing this folder is the
first external record.
