## 7. The rest of the tree

The change in name resolution applies to every module. `shadow_scan.py` (beside this file) looks,
in each `.ail` file, for a local binder that shares a name with a lowercase name in one of the
file's explicit import lists.

    $ python3 shadow_scan.py src packages scripts tools > shadow_scan.out.tsv
    # 494 files scanned, 6 candidate hits in 4 files

  - 403 of the 494 files have such imports, 4,952 imported names in all.
  - 3 hits are this suite's fixtures: `let make_hooks` in v7_delegate_import_shadow.ail and in
    gate/fx_delegate_import_shadow.ail, `let body` in gate/fx_import_shadow.ail.
  - 3 hits are in src/eval/journal/candidate_checks_live_test.ail (:424, :432, :437) and are false:
    `Ok(fs) => List.map(k_finding_label, fs)` uses the import on the right of an inline arm.
  - No binder is named `show`, `floatToInt` or `intToFloat` (searched separately, as `let`, as a
    typed parameter and as a lambda parameter).

Limits. It is a regular-expression heuristic, not a parser. It reads `let` and `letrec`, tuple
`let`, the parameters of named and anonymous `func`, backslash lambdas, and match arms whose
pattern and `=>` are on one line. It does not read a pattern that spans lines, and it knows only
names imported through an explicit list. A hit is a candidate to read; no hit is not a proof.
