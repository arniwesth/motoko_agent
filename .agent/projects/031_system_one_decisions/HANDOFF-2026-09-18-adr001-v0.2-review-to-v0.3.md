## What v0.3 must change (edit list, by section)

**Header / status.** v0.3; cite both reviews and NOTE-001.

**Current behavior table.** Row "`SolverJudge` has effect row `{Process}`; `ToolPolicy` is pure.
Neither can call the current AI port": qualify to *named or annotated bindings*; an unannotated
inline atom can (NOTE-001 §3, p1/p16/p18). Add a row for `journal.ail:28-31`: the child never
writes; the host is the one journal writer (feeds F2).

**D2 (F1).** Replace `ExtCtx` as the first parameter of `prepare` and `interpret` with a
**ports-free context** — an `ExtCtx` projection without `ports` and without `world` (name it;
`DecisionCtx` is fine). State that purity is guaranteed structurally (no port value in scope), and
that the compiler probe is a secondary gate that on v0.33.0 is known not to catch the projection
call shape. Delete or rewrite the sentence "The pure contract admits no port effects even though
`ExtCtx` contains ports." Keep the two-phase, positional, vote-family, descriptor and one-request
rules unchanged. Decide and state whether the *existing* rowless/narrow slots get the same
treatment at 8.0 (ports-free context for `PromptShaper`/`BudgetShaper`/`ToolPolicy`; per-slot
ports views for `SolverJudge {Process}`, `ExitIntent {FS}`, `WorkInFlight {FS}`); the review
recommends yes, since 8.0 is the only window — if deferred, say so and why.

**D3.** (i) `CommandExit(int)` excludes the `-1` sentinel (`ports.ail:645-646`), which maps to
`ToolOutcomeUnknown`. (ii) State that `ToolEvidenceWindow` needs new accumulation on `C2LoopState`
and that a resumed session's window is `complete_from_session_start = false` unless journal
schema 2 carries typed outcomes — choose. (iii) Note `is_missing_infrastructure` is a substring
heuristic, so `VerificationUnavailable` is a heuristic classification. (iv) The adapter sends no
`sessionId`/`user`/`trace` (the OpenRouter request type has them, optional) unless recorded as
part of the canonical request; recommend none. (N18, N19)

**D4.** Unchanged in substance. Optional: note the tool-phase leaf can follow the existing
`tool_exec` pattern (advance in `tool_phase.ail`, witness in `session.ail:3623`), so extracting
`witness` is not required (N22).

**D5 (F2).** Choose the transport and rewrite the four durability sentences to match:
- (a) **host-mediated over the wire** (recommended): the child's live `decision_query` arm emits
  the request and blocks on the reply — `ports.wake_read` / ADR-002 park-wake is the precedent;
  reservation → provider call → observation are host journal entries in host order; the port's
  row is `{IO}`; credentials stay host-side. "Durably record before dispatch" is then literally
  true.
- (b) child-side `Net` adapter: weaken to "emitted before dispatch; the host's write order is the
  durability order; the crash window between emission and host write is accepted", and add that
  window to freeze-evidence item 5.
Either way, add one sentence that conservatively-charged decision spend enters
`totals.cost_millicents` so `call_model_or_fail`'s `BudgetExceeded` sees it (N7 note).

**D6.** (i) State that backend-binding resolution, the configured maximum charge and the effective
limits are **recorded configuration inputs** to the program (ADR-004 D1 sense) or routed through
`env_get`, so preflight is replay-deterministic (N16). (ii) Define live `--resume` under a changed
descriptor with the same kind: either the descriptor snapshot enters the resume header comparison
(refuse; `--resume-force` overrides, like `Prompt`) or a resume appends a new policy-snapshot entry
and continues. Pick one (N17).

**D7.** (i) Attribute the `/5` bump to the new observation payload and scripts, not to the
identity constructor alone (`dst_interaction.ail:99-108` is the tree's rule; N21). (ii) Reconsider
the schema-1 live-resume refusal: a pre-feature journal truthfully has zero decision state, so a
superset fold with empty decision state is not fabrication; if the refusal is kept, state the
operator cost (every existing session non-resumable at the major) as accepted (N20).
